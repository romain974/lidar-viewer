lidar-viewer

Affichez une portion de dalle LiDAR HD de l'IGN dans n'importe quelle page web : on donne une adresse ou une emprise, la librairie télécharge les seuls blocs nécessaires (format COPC, requêtes HTTP Range) et rend le nuage de points en 3D.

Aucune clé d'API, aucun serveur, aucune dépendance de build. Données © IGN, open data.

Choisissez un lieu, ou cliquez sur une ville.

<div id="vue"></div>
<script src="https://cdn.jsdelivr.net/gh/romain974/lidar-viewer@main/dist/lidar-viewer.min.js"></script>
<script>
  LidarViewer.create({
    container: '#vue',
    center: [6.1294, 45.8992],  // [longitude, latitude]
    span: 150,                  // côté de l'emprise, en mètres
    height: 480
  })
</script>
